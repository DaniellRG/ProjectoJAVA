# ProjectoJAVA - Sistema de Registro de Mantenimiento de Computadores

Proyecto desarrollado en Java (Apache NetBeans con Swing) y base de datos relacional MySQL.

## Estructura del Repositorio
- **ProjectoJAVA/**: Carpeta del proyecto NetBeans.
  - `src/`: Código fuente Java (controladores, modelos y formularios Swing MDI).
  - `BasedeDatosProyecto.sql`: Script SQL con el modelo normalizado (3FN), vistas, triggers, funciones y procedimientos almacenados.
  - `TablaProyectoJava.mwb`: Diagrama entidad-relación / modelo de MySQL Workbench.
  - `mysql-connector-j-26.7.0/`: Conector JDBC de MySQL.
